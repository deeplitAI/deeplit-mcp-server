# Select models and GPUs

Use `list_gpus`, `list_gpu_offers`, `list_models`, `get_model`, `list_compatible_models`, and `list_model_compatible_instances` to compare supported choices.

Prefer compatible, currently available configurations. Present region, GPU count, provider, model compatibility, and quoted price when those fields are returned. Do not invent availability or pricing that is absent from the MCP response.
